A node is eight integers

There are no node objects. The whole graph lives in one Int32Array — the arena — carved into 32-byte records of eight int32 slots. A “signal” is a record id: the index of its first slot.

0 · Flags
kind tag + state bits: Mutable, Watching, Dirty, Pending, …
1 · Deps
head of the dependency list — points at a link record
2 · DepsTail
the re-track cursor into that list
3 · Subs
head of the subscriber list — also a link record
4 · SubsTail
tail of the subscriber list
5 · Gen
generation counter, so stale ids of freed records miss
6+7 · Version
one float64 (read through a shared-buffer view): “verified as of global version N”

Edges are records too: a link record’s slots name a dependency, a subscriber, and the four neighbors that thread it into both of their lists. Reading a signal inside a computed writes one of these records; that is the entire subscription mechanism.

Watch the integers move

A live graph — two signals, two computeds, one effect — over a real arena. The table is the actual memory; the diagram is drawn by following the pointers in it. Amber cells changed on the last action.

Painting writes a handful of signals; the change cascades down a widening cone of computeds. With equality cutoff on, cells that settle to the same value stop the cascade — the cone visibly narrows. “Invalidate everything” writes a signal every cell reads, recomputing the entire graph in one frame; the timer shows what that costs.
